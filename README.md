# PDF → Word (DOCX)

Простой конвертер PDF в редактируемый DOCX с распознаванием сканов (OCR) и прогрессом.
Готовый файл сразу открывается в Word.

```
Страниц: 32, с текстом: 30, сканов (OCR): 2
Конвертация:  58%|█████▊    | 00:08<00:04, стр. 16/32: разбор вёрстки
Готово: C:\Users\me\Documents\договор.docx
```

## Готовая программа для Windows: PDF2Word.exe

Один файл, ничего устанавливать не нужно: Tesseract с русским и английским языками встроен внутрь.

- Запустите `PDF2Word.exe` двойным щелчком → выберите PDF → дождитесь прогресса → документ откроется в Word.
- Или перетащите PDF прямо на значок `PDF2Word.exe`.
- Результат сохраняется рядом с PDF: `документ.pdf` → `документ.docx`.
- Первый запуск занимает несколько секунд: программа распаковывается во временную папку.
- Файл не подписан, поэтому Windows может показать «Система Windows защитила ваш компьютер» —
  нажмите «Подробнее» → «Выполнить в любом случае».

### Как собрать exe самому

1. Установите Tesseract (см. ниже, с языком Russian) и зависимости:
   `pip install -r requirements.txt pyinstaller`
2. Запустите `python build_exe.py` (или `python build_exe.py "путь\к\Tesseract-OCR"`).
3. Готовый файл: `dist\PDF2Word.exe` с иконкой из `assets\icon.ico`.

## Установка (для запуска как Python-скрипта)

1. Python 3.9+ и библиотеки:

   ```
   pip install -r requirements.txt
   ```

2. **Tesseract OCR** — нужен только для сканов (страниц-картинок):
   - **Windows:** установщик <https://github.com/UB-Mannheim/tesseract/wiki>,
     при установке в *Additional language data* отметьте **Russian**.
     Скрипт сам найдёт его в `C:\Program Files\Tesseract-OCR`.
   - **macOS:** `brew install tesseract tesseract-lang`
   - **Linux:** `sudo apt install tesseract-ocr tesseract-ocr-rus`

## Запуск

```
python pdf2word.py документ.pdf              # -> документ.docx рядом с PDF и сразу открывается
python pdf2word.py документ.pdf итог.docx    # свой путь для результата
python pdf2word.py                           # откроется окно выбора PDF
```

В Windows можно просто перетащить PDF на `pdf2word.py` или запустить его двойным щелчком.

Параметры:

| Параметр       | Что делает                                                  |
|----------------|-------------------------------------------------------------|
| `--lang`       | языки OCR, по умолчанию `rus+eng`                           |
| `--dpi`        | разрешение для OCR, по умолчанию 300                        |
| `--ocr`        | распознавать через OCR все страницы, даже с текстом         |
| `--no-open`    | не открывать результат после конвертации                    |

## Как это работает

- Для каждой страницы проверяется, есть ли в ней настоящий текст.
- **Страницы с текстом** конвертирует [pdf2docx](https://github.com/ArtifexSoftware/pdf2docx):
  сохраняются шрифты, таблицы, картинки и вёрстка.
- **Сканы** (а также PDF, где текст есть только в невидимом OCR-слое) распознаются
  Tesseract (нейросетевой движок LSTM, 300 DPI):
  - очистка «пыли» медианным фильтром, автоповорот страниц, отсканированных боком,
    выравнивание наклона скана;
  - линии таблиц находятся и убираются перед распознаванием, а потом рисуются заново —
    в Word получается настоящая таблица с текстом в ячейках;
  - фото, графики, печати и подписи вырезаются и вставляются картинками;
  - то, что Tesseract пропустил (одиночные цифры в ячейках и т.п.), дочитывается отдельно;
  - кегль определяется по ширине слов, жирный — по толщине штрихов; переносы слов склеиваются,
    маркеры списков становятся пунктами списка.

  Распознанный текст ставится на «чистую» PDF-страницу на те же места шрифтом
  Liberation Serif (метрически совпадает с Times New Roman), и её, как обычную страницу,
  разбирает pdf2docx — поэтому абзацы, выравнивание, отступы и таблицы получаются как в оригинале.
- Страницы без текста (например, фотографии) переносятся как картинки.
- После сборки DOCX: ширины колонок таблиц выравниваются по ячейкам, маркеры из шрифтов
  Symbol/Wingdings заменяются обычными «•», Liberation-шрифты — на Times New Roman / Arial.
- Если DOCX уже открыт в Word, результат сохранится как `документ (1).docx`.

Шрифты Liberation Serif в `assets/fonts` распространяются по лицензии SIL Open Font License 1.1
(`assets/fonts/OFL.txt`).
