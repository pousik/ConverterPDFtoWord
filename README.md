# PDF → Word (DOCX)

Конвертер PDF в редактируемый DOCX с распознаванием сканов (OCR) и прогрессом.
Готовый файл сразу открывается в Word.

Страницы переносятся **точной копией**: текст, таблицы, рамка документа и основная надпись (штамп)
стоят в Word ровно там же, где в PDF, и никуда не «уезжают». Текст и таблицы при этом редактируются.

```
Страниц: 32, с текстом: 30, сканов (OCR): 2
Конвертация:  58%|█████▊    | 00:08<00:04, стр. 16/32: разбор вёрстки
Готово: C:\Users\me\Documents\договор.docx
```

## Сборка программы для Windows

1. **Python 3.10–3.13** с [python.org](https://www.python.org/downloads/windows/)
   (при установке отметьте «Add python.exe to PATH»).
2. **Tesseract OCR** — установщик <https://github.com/UB-Mannheim/tesseract/wiki>.
   При установке в *Additional language data* отметьте **Russian**.
   Если Tesseract установлен не в `C:\Program Files\Tesseract-OCR`, укажите папку перед сборкой:
   `set TESSERACT_DIR=D:\Tesseract-OCR`.
3. В папке проекта:

   ```
   py -m pip install -r requirements.txt "pyinstaller>=6.10"
   py -m PyInstaller PDF2Word.spec
   ```

4. Готово: **`dist\PDF2Word\PDF2Word.exe`** с иконкой из `assets\icon.ico`. Папку `dist\PDF2Word` можно
   копировать на другие компьютеры — Tesseract с русским и английским языками, шрифты и библиотеки уже внутри.

Собирайте именно через `PDF2Word.spec`, а не `pyinstaller pdf2word.py`: spec кладёт в сборку Tesseract
(только нужные ему файлы), языки, шрифт для распознанного текста и иконку и собирает программу с консолью
(в ней показывается прогресс). Без Tesseract на компьютере сборки spec выдаст предупреждение, и программа
будет распознавать сканы, только если Tesseract установлен там, где её запускают.

Один exe-файл вместо папки (его удобнее передавать, но каждый запуск дольше на несколько секунд: перед
стартом он распаковывает ~230 МБ во временную папку):

```
set PDF2WORD_ONEFILE=1
py -m PyInstaller PDF2Word.spec
```

## Как пользоваться

- **Двойной щелчок** по `PDF2Word.exe` — откроется окно выбора, можно выбрать сразу несколько файлов.
- **Перетащите** один или несколько PDF на `PDF2Word.exe` или на его ярлык на рабочем столе.
- Результат сохраняется рядом с PDF (`документ.pdf` → `документ.docx`) и сразу открывается в Word.
- **Существующие файлы никогда не перезаписываются**: если `документ.docx` уже есть (или открыт в Word),
  результат получит имя `документ (1).docx`. Если в папку с PDF нельзя записать, результат сохранится
  в «Документы» — программа об этом скажет.
- Сканы-картинки (JPG, PNG, TIFF…) тоже можно конвертировать — как одностраничный скан.
- Для PDF с паролем программа спросит пароль (три попытки).
- Если что-то пошло не так (ошибка, страница вставлена картинкой), окно не закроется, пока вы не нажмёте Enter.

Командная строка:

```
PDF2Word.exe документ.pdf                    -> документ.docx рядом с PDF
PDF2Word.exe a.pdf b.pdf c.pdf               -> три DOCX, каждый рядом со своим PDF
PDF2Word.exe документ.pdf -o итог.docx       -> свой файл (только он может быть перезаписан)
PDF2Word.exe *.pdf -o D:\Готовое             -> все результаты в папку
```

| Параметр           | Что делает                                                      |
|--------------------|-----------------------------------------------------------------|
| `-o`, `--output`   | файл `.docx` (для одного PDF) или папка для результатов          |
| `--lang`           | языки OCR, по умолчанию `rus+eng`                               |
| `--dpi`            | разрешение для OCR, 100–600, по умолчанию 300                    |
| `--ocr`            | распознавать через OCR все страницы, даже с текстом             |
| `--flow`           | обычная вёрстка вместо точной копии (см. ниже)                  |
| `--no-open`        | не открывать результат после конвертации                        |

## Как это работает

- Каждая страница PDF становится отдельной страницей Word того же размера (A4, A3, альбомная — как в PDF).
  Всё размещается относительно страницы, а не «течёт» друг за другом, поэтому ничего не сдвигается —
  ни при открытии, ни на другом компьютере, ни при правке соседнего текста.
- **Текст** — абзацы Word в рамках, закреплённых на странице: строки разбиты как в оригинале, сохраняются
  шрифт, кегль, жирность, курсив, цвет и выравнивание (по ширине, по центру, по правому краю).
- **Таблицы** (с линиями) — настоящие таблицы Word на своём месте: ширины колонок и высоты строк как в PDF,
  объединённые ячейки, толщина линий, заливка, текст каждой ячейки — в своей ячейке, с тем же выравниванием.
  Повёрнутый текст в ячейках остаётся повёрнутым.
- **Рамка документа, основная надпись (штамп), линии, картинки, печати** — подложка за текстом, привязанная
  к странице. Надписи в штампе («Изм.», «Лист», шифр документа…) — обычный редактируемый текст на своих
  местах поверх линий. Повёрнутые надписи на полях рамки («Инв. № подл.», «Подп. и дата») остаются частью
  подложки.
- **Сканы** распознаются Tesseract (нейросетевой движок LSTM, 300 DPI) параллельно, по странице на ядро:
  очистка «пыли», выравнивание фона, автоповорот и выравнивание наклона, поиск линий таблиц, кегль
  и жирность по самим буквам. Распознанный текст ставится на те же места, что и на скане, таблицы становятся
  таблицами Word. Страница без распознаваемого текста (фото) или при отсутствии Tesseract вставляется картинкой.
- Страница, которую не удалось разобрать по частям, вставляется картинкой — ни одна страница не теряется
  молча, а программа об этом предупредит.

### Обычная вёрстка (`--flow`)

`PDF2Word.exe документ.pdf --flow` — прежний режим через [pdf2docx](https://github.com/ArtifexSoftware/pdf2docx):
сплошной текст, который Word раскладывает сам. Длинный текст в нём удобнее дописывать (абзацы переливаются
со страницы на страницу), но строки, рамки и таблицы могут сдвинуться относительно оригинала.

## Если что-то не работает

- **«Система Windows защитила ваш компьютер»** — программа не подписана: «Подробнее» → «Выполнить в любом случае».
- **`DLL load failed`** при запуске на другом компьютере — установите
  [Microsoft Visual C++ Redistributable (x64)](https://aka.ms/vs/17/release/vc_redist.x64.exe)
  или пересоберите программу на компьютере, где он установлен (spec тогда положит эти библиотеки в сборку).
- **«Tesseract OCR не найден — сканы будут вставлены картинками»** — при сборке не был найден Tesseract:
  установите его (с языком Russian) и пересоберите, или укажите папку через `TESSERACT_DIR`.
- Антивирус иногда ложно срабатывает на программы, собранные PyInstaller, — добавьте папку в исключения.

## Запуск как Python-скрипта

```
pip install -r requirements.txt
python pdf2word.py документ.pdf
```

Для сканов нужен Tesseract: Windows — установщик выше; macOS — `brew install tesseract tesseract-lang`;
Linux — `sudo apt install tesseract-ocr tesseract-ocr-rus`.

Шрифты Liberation Serif в `assets/fonts` распространяются по лицензии SIL Open Font License 1.1
(`assets/fonts/OFL.txt`).
